SemEval-2022 Task 4 • 10,469 News Paragraphs • 10 Vulnerable Communities

Detecting Condescension Disguised as Kindness ↗

Patronising language rarely uses explicit slurs; it hides in sympathetic or saviour framing. Prepending Community: {keyword} before tokenisation gives the 24-layer roberta-large encoder explicit target context to separate genuine reporting from subtle condescension.

Countering 9.54:1 Class Imbalance Without Precision Collapse ↗

Weighting positive examples in BCEWithLogitsLoss prevents majority-class collapse but inflates raw probabilities. Calibrating the decision boundary to τ = 0.77 cuts validation false positives from 81 to 24 while preserving 54% recall.
